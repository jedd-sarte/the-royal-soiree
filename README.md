# The Royal Soirée

A responsive one-page event website for The Royal Soirée honoring Selina A. Robinson-Coleman and Dairyl A. Gray, Esq.

## Live website

https://jedd-sarte.github.io/the-royal-soiree/

## Preview

Open `index.html` directly, or serve the folder locally for the best preview:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html`: page content and metadata
- `styles.css`: responsive styling and motion
- `script.js`: reveal effects, sticky header state, and RSVP countdown
- `assets/royal-soiree-invitation.jpg`: supplied invitation artwork
- `assets/royal-soiree-backdrop.jpg`: generated supporting background asset

## RSVP destination

All RSVP buttons point to the official Greenvelope invitation provided for the event.
